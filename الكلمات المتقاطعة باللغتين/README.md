# الكلمات المتقاطعة باللغتين

هذا المجلد مخصص لتوثيق ومتابعة مشروع الكلمات المتقاطعة العربية والإنجليزية داخل موقع سكاكر.

## ملف التشغيل

- [واجهة API للكلمات المتقاطعة](../functions/api/crossword.js)

المسار المنشور للواجهة البرمجية:

`/api/crossword`

## اللغات

- العربية: بنك كلمات وتلميحات عربية مستقل.
- English: an independent English word bank, with optional definition lookup and local fallback hints.

## آلية العمل الحالية

- اختيار لغز يومي مستقل بحسب اللغة وتاريخ الرياض.
- تخزين مؤقت لمدة 24 ساعة لتسريع الاستجابة وتقليل الاعتماد على توفر المصادر الخارجية.
- توفير بيانات اللغز وموعد إتاحة الحل في اليوم التالي عبر حقول الاستجابة.
- لا يعتمد هذا المشروع على ويكيبيديا.

## ملاحظات التطوير

هذا المجلد للتوثيق والتنظيم، أما منطق تشغيل الـ API فيبقى في الملف المرتبط أعلاه. يجب إجراء أي تعديل تشغيلي على الملف الأصلي مع الحفاظ على تكامل الموقع وبقية أقسامه.
