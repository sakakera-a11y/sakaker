# SAKAKER split workspace

مساحة عمل لتقسيم الملف الرئيسي الكبير دون التأثير على الموقع المنشور.

الصفحات المستهدفة:
- pong.html — لعبة بونج والغرف الخاصة والعامة
- chess.html — الشطرنج
- draw.html — استوديو الرسم والبطاقات
- videos.html — القنوات المباشرة ومكتبة الفيديو
- books.html — المكتبة النصية والكتب الإلكترونية

لا يتم تعديل index.html المنشور حتى اكتمال الفصل والفحص.
